# Khep

**箧** (box, chest). Yixuan's personal collection of agentic coding facilities.

## Installation

If you have `npm` installed, you can use the [`skills`](https://www.npmjs.com/package/skills) CLI to install Skills.

```bash
## Install one specific skill
npx skills add https://github.com/Yixuan-Wang/khep --skill <skill>
## Install every skill
npx skills add https://github.com/Yixuan-Wang/khep
```
